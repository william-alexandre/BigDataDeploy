# Implementação em Big Data - SENAI

Este repositório contém as atividades e projetos realizados durante o curso de **Implementação em Big Data** oferecido pelo SENAI. O curso abordou o uso de ferramentas e arquiteturas de Big Data, com ênfase no ecossistema Hadoop e na manipulação de grandes volumes de dados.

## Objetivos do Curso

Durante o curso, desenvolvi habilidades nas seguintes áreas:

- **Identificação das arquiteturas em Big Data**: Aprendi sobre as principais arquiteturas usadas em Big Data, como Hadoop, Spark e outras tecnologias distribuídas.
- **Aplicação do ecossistema Hadoop**: Pratiquei o uso do Hadoop, incluindo o HDFS (Hadoop Distributed File System) e o MapReduce, para processamento e armazenamento de grandes volumes de dados.
- **Manuseio de grandes volumes de dados**: Realizei atividades de processamento, análise e visualização de grandes volumes de dados utilizando ferramentas como Hive, Pig, e Spark.
- **Implementação de soluções em Big Data**: Criei soluções práticas para processamento de dados em larga escala, utilizando as ferramentas e tecnologias aprendidas durante o curso.
- **Criação de modelos personalizados**: Desenvolvi modelos personalizados de análise de dados para resolver problemas específicos de negócio.
- **Habilidades interpessoais**: Demonstrei capacidade de organização, atenção aos detalhes e raciocínio lógico, habilidades essenciais para trabalhar com Big Data.


## Tecnologias Utilizadas

- **Hadoop** (HDFS, MapReduce)
- **Spark**
- **Hive**
- **Pig**
- **Python** (para scripts e análise de dados)
- **Colab Notebook** (para análise e visualização de dados)
